# MSc Artificial Intelligence — Graded Projects

Graded project submissions from the MSc in Artificial Intelligence at the
Udacity Institute of AI & Technology (degree awarded by Woolf).

This repository contains **projects only**. Lesson notes, exercises and working
files are kept in a separate private repository.

Each project sits under its nanodegree, and each project folder contains its own
README describing that project's implementation.

## Nanodegrees

### nd901 — Agentic AI with LangChain and LangGraph

| Project | Description |
|---|---|
| [Report-Building Agent](./nd901-agentic-ai-langchain-langgraph/report-building-agent) | Multi-agent document assistant built with LangGraph. Classifies user intent, routes to a Q&A, summarization or calculation agent, uses document and calculator tools, and maintains conversation memory across turns. |

## Running a project

Each project is self-contained. See the README inside the project folder for its
own setup and run instructions.

No API keys or credentials are committed to this repository. Each project
includes an `env.example` showing the variables required.
